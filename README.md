# Döneria 56

A local business project created to build a landing page for a kebab shop based on specific customer requirements

### Project Purpose
Deliver a finished product by translating customer wishes into a functional website. The focus was on communication, handling feedback, and solidifying core web technologies

### Lessons learned
* **Client Communication**: Managing expectations and building trust with a skeptical customer
* **Project Management**: Moving out of the comfort zone to handle a complete end-to-end delivery
* **Feedback Loops**: Implementing specific changes based on critique to meet the client's vision
* **HTML, CSS and JS**: Applying foundational styling to a real-world business use case
